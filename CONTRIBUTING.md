# Contributing to Steerify

Thanks for wanting to help. Steerify is a small project, so the process is short.

## Bugs and ideas

Open an issue at https://github.com/thisfiore/steerify/issues. For bugs, include your macOS version,
the Steerify version (see `VERSION`) and the steps to reproduce. For ideas, describe the problem you
are trying to solve before the solution.

## Pull requests

1. For anything bigger than a small fix, open an issue first so we agree on the direction.
2. Build and try your change locally:
   ```sh
   scripts/bundle.sh
   open build/Steerify.app
   ```
   Requires macOS 15 or later.
3. Keep each pull request to one change and say what you tested.
