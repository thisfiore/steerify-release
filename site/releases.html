What's new

Eleven releases. Four days.

Every line below shipped through Steerify's own board: built by Claude, looked at, marked OK.

Yes, we know. It was a long day.

v0.5.621 Nov

Every feature keeps its pictures.

  • Roadmap, rebuilt

    Each key result shows its pictures, design first, then the test shots. Area tags named by the local AI, core vs extras, busiest chapter on top, Done folded.

  • Mark the picture

    In a new request the picture opens big: ⌘-click drops a numbered dot, drag marks an area, and ① ② go into your text.

  • Simple choices, one list

    Naming, order or yes/no: one list with a radio per option, no empty picture.

  • Ready: where you left off

    Your chapters, the next step and what waits on you, in one tab. Release sits apart from build, with a release note for Claude.

  • Picks reach the session that asked

    Answer a choice and the session that asked it gets it, once all its choices are answered. A deploy wakes the session waiting on it.

v0.5.520 Nov · evening

Not only code.

  • Tasks

    A new tab for work Claude does with your tools: a tutorial from the SOP, a weekly report. Once or on a schedule; every run ends with a result you OK or Redo, or shows No result.

  • Sessions you can read at a glance

    Rowing is blue, your turn is violet with Test or Answer, done is grey with a tick.

  • Next strip

    At most two things to do now, on top of the board, one button each.

  • Drop a folder to start

    Drop a folder on the Dock icon or the window. Set up with Claude, then watch the board fill in.

  • Test it opens the feature

    Links to a home page or a dead page are refused, so Test it always lands on the thing to check.

v0.5.2–0.5.420 Nov

It updates itself.

  • Updates in the background

    New versions download by themselves. Hover Restart to update to see what's in it.

  • Requests, faster

    Your latest screenshots one click away, the project guessed from what you type, and a request for another project stays there.

  • First setup asks with choices

    Claude runs your app, shows what it understood and asks with pictures, not a wall of questions.

  • Where to test

    Each project lists its real test addresses; links anywhere else are refused.

  • Demo project

    Tiny Todo comes with the app: try every screen before touching your own code.

v0.519 Nov

Ask from anywhere.

  • New request (⌘N)

    A fix, a tweak, a feature or a question, with screenshots. Steerify shows where it goes, then starts a briefed Claude session.

  • From any app (⌃⌥N)

    The menu bar opens a request anywhere and asks which project. A compact panel, by priority.

  • Ready to build

    One request, one row, one session. One line per topic.

  • Since you left

    What moved while you were away, and local AI helpers for session summaries and request triage.

  • Guided choices

    Choices as a guided decision; ⌘K finds them by their content.

v0.418 Nov · evening

It knows who is working.

  • Release tab

    Everything you approved, per repo, with its git state and a Deploy button. Set up once in steerify.json.

  • Sessions know their state

    From Claude Code hooks: working, waiting on you, idle. Your answers move them forward on their own.

  • Menu bar

    A pixel wheel with a count when it's your turn: who's rowing, what waits on you.

  • Steerify MCP

    Claude updates the board and your window directly: deliver, ask a choice, set roadmap status.

  • Consolidate chapters

    The roadmap catches up with what is really done, with evidence, one click to apply.

v0.318 Nov · afternoon

Visual first.

  • Tests as visual chapters

    One picture, a short title, Test it, Looks right. Progress and a suggested verdict.

  • Pictures first

    Big hero picture and filmstrip on every item; choice mockups shown as pictures.

  • Drop screenshots into the terminal

    Files and images go straight to Claude; ⌘V pastes images too.

  • Next for you (⌘J)

    The one thing that waits on you, from any tab. Resume a whole chapter with one button.

  • Restart to update

    New builds install themselves; your sessions come back.

v0.218 Nov · midday

Native, and wired.

  • The board, in Swift

    To test, Choices, Requirements, Roadmap: native, wired to the terminals.

  • Notes pinned on pictures

    ⌘-click a picture to pin a note exactly where it's wrong.

  • ⌘K

    Search sessions and items; open an item together with its session.

v0.118 Nov · morning

One window.

  • Board + terminals + projects

    Every project's board next to the Claude Code sessions doing the work.

  • Start from an item

    Every board item starts or resumes its own Claude session, already briefed.

  • The steerify skill

    Every session follows the same loop: read, ask, deliver, ship.
